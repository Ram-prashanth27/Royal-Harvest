# 🍴 Royal Harvest – Food Delivery App

A conceptual **food delivery application** UI/UX project designed with a focus on **modern, clean, and user-friendly design**.  
This project demonstrates the end-to-end design workflow from wireframes to high-fidelity prototypes.

---

## 📖 Overview
Royal Harvest is a fictional food delivery platform built to showcase design skills in **Figma**, **Adobe Illustrator**, and **Photoshop**.  
The goal was to create an engaging user experience with intuitive navigation and visually appealing layouts.

---

## ✨ Features
- 🎨 **Modern UI Design** – Clean layouts and consistent color palette.  
- 📱 **User-Friendly Navigation** – Simple and intuitive flows for browsing and ordering.  
- 🖼 **Custom Graphics** – Icons and assets designed in Illustrator & Photoshop.  
- 🧩 **Prototype Ready** – Clickable flows built in Figma to simulate app experience.  

---

## 🛠 Tools & Technologies
- **Figma** – UI/UX design and prototyping  
- **Adobe Illustrator** – Vector graphics and custom icons  
- **Adobe Photoshop** – Image editing and visual assets
